## Known limitations

- The deterministic model provider uses bounded templates. Requirement understanding,
  ambiguity classification, and repair are keyword/template driven; the OpenAI Responses
  provider is required for open-ended requirements.
- Generated code lives in `com.assessment.generated.urlshortener` and is validated in
  isolation; it is not merged into the platform's own shortener module.
- Per-node task leases are persisted and tested but not yet claimed by the in-process
  runner; multi-instance execution relies on `async` + restart recovery.
- OIDC/JWT, TLS, managed secrets, and multi-region deployment are operator
  responsibilities documented in `PRODUCTION-DEPLOYMENT.md`.
